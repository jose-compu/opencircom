Concept

What is OpenCircom?

Building ZK apps means reimplementing the same primitives — Poseidon hashes, Merkle inclusion, nullifiers, vote commitments — in every project. OpenCircom packages them as composable, documented Circom templates with no dependency on circomlib, so you include one path and start wiring circuits.

🔐

No circomlib

Self-contained implementations. Poseidon uses standard Hades parameters; comparators, gates, and Merkle trees are built in-house and range-checked.

🧪

Real ZK tests

153+ tests compile circuits, run Powers of Tau setup, generate Groth16 proofs with snarkjs, and verify — no mocks on the critical path.

📦

Drop-in includes

Install via npm, pass -l node_modules/opencircom/circuits to circom, or use boilerplates that wire the full compile → verifier flow.

Tooling

CLI — new in 0.7.0

Requires circom 2.x on PATH (peer dependency). The CLI adds the include path automatically and scaffolds starter circuits.

npx opencircom path

Print include path for manual -l flags.

npx opencircom compile circuit.circom -o build

Compile with opencircom circuits on the include path.

npx opencircom compile --all-test -o build

Compile all library test wrappers (used by npm test).

npx opencircom list

List exported templates with descriptions from circuit comments.

npx opencircom init my_circuit

Scaffold a minimal Poseidon commitment circuit and mocha test.

Developers

Quick start

Install from npm, include templates in your circuit, and compile with the opencircom path.

npm install opencircom
include "opencircom/circuits/hashing/poseidon.circom";
include "opencircom/circuits/merkle/merkle_inclusion.circom";

template MyCircuit(levels) {
    signal input secret;
    signal input pathElements[levels];
    signal input pathIndices[levels];
    signal output root;

    component hasher = Poseidon(1);
    hasher.inputs[0] <== secret;

    component tree = MerkleInclusionProof(levels);
    tree.leaf <== hasher.out;
    for (var i = 0; i < levels; i++) {
        tree.pathElements[i] <== pathElements[i];
        tree.pathIndices[i] <== pathIndices[i];
    }
    root <== tree.root;
}
> npx opencircom compile circuits/MyCircuit.circom -o build
> npx opencircom list
> npm run docs
